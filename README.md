# CourtOS

AI-powered basketball training and shooting analysis platform.

## Current Features

- Upload a basketball shooting video
- Preview the uploaded video in the browser

## Planned Features

- Pose detection
- Elbow angle analysis
- Knee angle analysis
- Release point analysis
- Shooting consistency tracking
- Player progress dashboard

## Tech Stack

- HTML
- CSS
- JavaScript

## Status

CourtOS is currently in early development.
